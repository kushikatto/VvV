# VvV Messenger

پیام‌رسان خصوصی با ورود نام کاربری/رمز عبور، جستجوی کاربران، پنل مدیر و رابط واکنش‌گرا برای موبایل.

## راه‌اندازی Supabase
1. در Supabase پروژه بسازید.
2. محتوای `schema.sql` را در SQL Editor اجرا کنید.
3. در Authentication تنظیم Confirm email را خاموش کنید.
4. در `config.js` آدرس پروژه و کلید Publishable/anon را قرار دهید. هرگز Secret یا service_role را در فایل مرورگر قرار ندهید.
5. فایل‌های داخل پوشه را در ریشه GitHub repository آپلود و GitHub Pages را فعال کنید.

## ساخت حساب مدیر
1. در برنامه با نام کاربری `admin` ثبت‌نام کنید.
2. چون رمز `admin` فقط ۵ کاراکتر است و حداقل رمز برنامه ۶ کاراکتر است، برای امنیت از رمز قوی‌تر مانند `admin123` استفاده کنید.
3. در Supabase > SQL Editor این دستور را اجرا کنید:

```sql
update public.profiles set is_admin = true where username = 'admin';
```

بعد از خروج و ورود دوباره، حساب admin فهرست کامل کاربران را می‌بیند. کاربران عادی فهرست را نمی‌بینند و فقط با جستجوی حداقل دو حرف از نام کاربری، نتایج محدود دریافت می‌کنند.

## قابلیت‌ها
- گفتگوی خصوصی یک‌به‌یک و Realtime
- جستجوی سمت سرور با RPC؛ عدم دسترسی عادی به فهرست کامل کاربران
- دسترسی مدیر با پرچم دیتابیس و RPC مجزا
- تنظیمات حساب: مشاهده نام کاربری/نقش و تغییر رمز عبور
- چیدمان موبایل با جابه‌جایی بین فهرست و گفتگو


## تغییرات نسخه جدید
- بخش «پیشنهاد ها» فقط برای مدیر نمایش داده می‌شود؛ پیشنهادهای کاربران به‌صورت زنده در این صندوق دریافت می‌شوند.
- در تنظیمات، فرم ارسال پیشنهاد و بخش «درباره ما» با نام سازنده Kushi و ایمیل Kushikatto@gmail.com اضافه شده است.
- ساختار دیتابیس سرورها و اعضای سرور ایجاد شده، اما RLS بدون policy باقی مانده و ساخت/مدیریت سرور فعلاً از سمت کاربران غیرفعال است.

**مهم:** پس از جایگزین کردن فایل‌ها، نسخه جدید `schema.sql` را یک‌بار در Supabase SQL Editor اجرا کنید. دستورات این فایل برای اجرای مجدد هم ایمن طراحی شده‌اند. سپس فایل‌ها را در GitHub Pages منتشر کنید.


## اتصال Steam (نسخه آزمایشی)
1. در تنظیمات هر حساب، Steam ID 64-bit هفده‌رقمی وارد و ذخیره شود. Steam profile باید Public باشد.
2. در Steam، از صفحه Steam Web API Key یک API Key دریافت کنید.
3. پوشه `supabase/functions/steam-status` را با Supabase CLI منتشر کنید:
   - ابتدا پروژه را لینک کنید: `supabase link --project-ref YOUR_PROJECT_REF`
   - `supabase secrets set STEAM_API_KEY=YOUR_STEAM_WEB_API_KEY`
   - `supabase functions deploy steam-status`
4. migration موجود در `schema.sql` را در Supabase SQL Editor اجرا کنید. این نسخه ستون `steam_id` را اضافه می‌کند و RPC جستجو/مدیر را برای برگرداندن آن به‌روزرسانی می‌کند.

کلید Steam فقط به‌صورت Secret در Edge Function نگهداری می‌شود و در مرورگر قرار نمی‌گیرد. وضعیت‌ها هر ۶۰ ثانیه تازه‌سازی می‌شوند. اگر پروفایل Steam خصوصی باشد یا Steam اطلاعات وضعیت را برنگرداند، وضعیت قابل نمایش نیست.


## اصلاح جستجوی کاربران
- جستجو برای کاربران عادی بر اساس نام کاربری و نام نمایشی انجام می‌شود.
- فهرست کامل کاربران همچنان فقط برای مدیر قابل مشاهده است.
- در صورت خطای RPC جستجو، پیام راهنما در رابط کاربری نمایش داده می‌شود.
- برای فعال شدن جستجوی نام نمایشی، نسخه جدید `schema.sql` را در Supabase SQL Editor اجرا کنید.


## اصلاحات رابط و تاریخچه گفتگوها
- در موبایل، صفحه گفتگو تمام‌صفحه و جدا از فهرست است؛ در دسکتاپ چیدمان دوپنجره‌ای حفظ می‌شود.
- فهرست گفتگوهای قبلی از پیام‌های موجود ساخته می‌شود و با RPC امن فقط مخاطب‌هایی را برمی‌گرداند که واقعاً با کاربر گفتگو داشته‌اند.
- تعداد پیام‌های خوانده‌نشده در کنار هر گفتگو نمایش داده می‌شود؛ باز کردن گفتگو پیام‌های دریافتی را خوانده‌شده می‌کند.
- اعلان داخل برنامه و اعلان مرورگر (در صورت فعال‌سازی و اعطای اجازه مرورگر) برای پیام جدید اضافه شده است. اعلان مرورگر فقط وقتی سایت باز است و تب در پس‌زمینه قرار دارد کار می‌کند؛ اعلان Push در زمان بسته بودن کامل سایت در این نسخه وجود ندارد.
- جستجو با دکمه ذره‌بین باز و بسته می‌شود.
- اسکرول فهرست گفتگوها، نتایج جستجو و پیام‌ها مستقل شده است.

## راه‌اندازی / به‌روزرسانی Steam
اگر Steam فقط «در حال بررسی» نشان می‌دهد، Edge Function هم باید در Supabase منتشر شده باشد و کلید API در Secret تنظیم شود:
1. Supabase CLI را نصب و به پروژه لینک کنید: `supabase link --project-ref YOUR_PROJECT_REF`
2. کلید را به‌صورت Secret ذخیره کنید: `supabase secrets set STEAM_API_KEY=YOUR_STEAM_WEB_API_KEY`
3. تابع را منتشر کنید: `supabase functions deploy steam-status`
4. مطمئن شوید Steam Profile روی Public است و Steam ID همان شناسه ۶۴ بیتی ۱۷ رقمی است.

نسخه جدید `schema.sql` را در SQL Editor اجرا کنید تا ستون read_at، مجوز خواندن پیام‌ها و RPC تاریخچه گفتگوها ایجاد شود.
