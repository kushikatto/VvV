# VvV — پیام‌رسان متنی

نسخه اول VvV دارای تم تیره، ثبت‌نام و ورود با نام کاربری و رمز عبور، فهرست کاربران و گفتگوی خصوصی متنی لحظه‌ای است.

## فایل‌ها
- `index.html` رابط کاربری
- `config.js` آدرس پروژه و کلید عمومی Supabase
- `schema.sql` ساخت جدول‌ها و قوانین امنیتی دیتابیس

## راه‌اندازی Supabase
1. در https://supabase.com یک پروژه بساز.
2. در SQL Editor محتوای `schema.sql` را اجرا کن.
3. از Project Settings → API مقدار Project URL و کلید `anon` یا `publishable` را بردار و در `config.js` قرار بده.
4. در Authentication → Providers → Email، گزینه تأیید ایمیل (Confirm email) را خاموش کن. کاربران در VvV ایمیل وارد نمی‌کنند؛ برنامه نام کاربری را پشت صحنه به یک شناسه داخلی ساختگی تبدیل می‌کند تا Supabase Auth بتواند حساب را مدیریت کند.
5. در Authentication → URL Configuration آدرس نهایی GitHub Pages را به Site URL و Redirect URLs اضافه کن.

## انتشار در GitHub Pages
1. یک repository جدید بساز و فایل‌های `index.html`، `config.js` و `schema.sql` را در ریشه آن بارگذاری کن.
2. در Settings → Pages گزینه Deploy from a branch، شاخه `main` و پوشه `/ (root)` را انتخاب کن.
3. آدرس سایت ساخته‌شده را در تنظیمات URL پروژه Supabase ثبت کن.

## قوانین نام کاربری
نام کاربری باید یکتا، ۳ تا ۲۴ کاراکتر و شامل حروف انگلیسی کوچک، عدد، نقطه، خط تیره یا زیرخط باشد. رمز عبور حداقل ۶ کاراکتر است.

## امنیت
- فقط کلید عمومی `anon` یا `publishable` را در `config.js` بگذار؛ کلید `service_role` هرگز نباید در مرورگر قرار بگیرد.
- RLS طوری تنظیم شده که هر کاربر فقط پیام‌هایی را بخواند که فرستنده یا گیرنده آن است.
- برای نسخه عمومی، محدودیت تلاش ورود، CAPTCHA و سیاست رمز عبور قوی‌تر هم توصیه می‌شود.
- این نسخه فعلاً چت خصوصی یک‌به‌یک و متن را پشتیبانی می‌کند؛ گروه، فایل، عکس و تماس هنوز اضافه نشده‌اند.
